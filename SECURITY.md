# Security policy

This is the default policy for Gantrly's repositories. A repository with its own
`SECURITY.md` (such as [Mobius Guard's](https://github.com/gantrly/mobius-guard/security/policy))
follows that one instead.

## Reporting a vulnerability

**Please don't open a public issue, pull request or discussion.** Report privately through
GitHub's private vulnerability reporting: **Security → Report a vulnerability** on the
repository's page. Only the maintainers can see the report. Please include:

- what you found and which part it affects;
- the version or commit;
- the smallest steps or input that reproduce it;
- what an attacker could do with it.

If the repository has no **Report a vulnerability** button, open an issue that says only
that you have a security report and asks for a private channel; don't include any detail.

## What happens next

We acknowledge your report within **3 working days**, confirm whether it is a
vulnerability within **7 days**, and keep you informed until it is fixed. We agree the
disclosure date with you and credit you in the advisory and the release notes, unless you
prefer not to be named.
