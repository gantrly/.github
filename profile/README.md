**An open-source firewall for LLM apps.** It rewrites secrets in a streamed reply
without stopping the stream, blocks prompt injection with its own CPU classifier, and
reports every number on data the detector never saw.

[Repository](https://github.com/gantrly/mobius-guard) ·
[PyPI](https://pypi.org/project/mobiusguard/) ·

## Working with us

- **Report a security issue** privately, never in a public issue: on the repository,
  **Security → Report a vulnerability**. See our [security policy](https://github.com/gantrly/.github/blob/main/SECURITY.md).
- **Ask a question** in [Mobius Guard's discussions](https://github.com/gantrly/mobius-guard/discussions).
- **Contribute:** each repository's `CONTRIBUTING.md` says how. Everyone follows our
  [code of conduct](https://github.com/gantrly/.github/blob/main/CODE_OF_CONDUCT.md).
