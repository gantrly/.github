# Getting help

- **A question about using a project:** its Discussions tab, where it has one (for example
  [Mobius Guard's](https://github.com/gantrly/mobius-guard/discussions)).
- **A bug or a feature request:** an issue on the project's repository.
- **A security problem:** never in public; see the [security policy](SECURITY.md).

We are a small team, so answers can take a few days.
