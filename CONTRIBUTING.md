# Contributing

Thanks for helping. This is the default guide for Gantrly's repositories; a repository's
own `CONTRIBUTING.md` comes first and has its setup, checks and rules.

- **Bugs and small fixes:** open a pull request, and link the issue if there is one.
- **Anything bigger** (a new feature, a new dependency, a change to how something works):
  open an issue first, so we can agree the shape before you spend the time.
- **Sign your work.** Repositories say which they use: a sign-off on each commit
  (`git commit -s`, the [Developer Certificate of Origin](https://developercertificate.org/))
  or a Contributor Licence Agreement that a bot asks you to sign on your first pull
  request.
- **Security issues** go through private reporting, never a public issue: see the
  [security policy](SECURITY.md).

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
